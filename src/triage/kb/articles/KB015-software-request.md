Approved software can be installed from the Company Portal without a ticket; anything else needs a software request.

1. Check the Company Portal app first. Approved software there installs without admin rights.
2. If what you need is not there, raise a software request with the business reason and your manager's approval. Paid software needs a cost code.
3. New software is checked for security and data protection before it is approved. This can take up to five working days.
