---
id: KB006
title: Shared and mapped network drives are missing or slow
category: network
keywords: S drive, H drive, P drive, shared drive, mapped drive, network path not found, red cross, access denied, folder permission, network folder
---
Network drives only appear when you are on the office network or the VPN, and you need permission for each folder.

1. Make sure you are on the office network or connected to the VPN.
2. Sign out of Windows and back in. Drive mappings are applied when you sign in.
3. If one folder says "access denied" but the rest of the drive works, you need permission to that folder. Ask the folder owner or your manager to request access.
4. If the whole drive is slow for many people at once, report it as an incident and mention which drive and site.
