---
id: KB002
title: Set up multi-factor authentication (MFA) on a new phone
category: access
keywords: MFA, authenticator, two-factor, 2FA, verification code, new phone, sign-in approval
---
If you have a new phone, or the Authenticator app has stopped working, you need to register the app again.

1. Install Microsoft Authenticator on the new phone from the app store.
2. On a computer, sign in to the "My Sign-Ins / Security info" page. If you can still approve sign-ins on the old phone, add the new phone as a sign-in method, then remove the old one.
3. If you no longer have the old phone, ask the service desk for a temporary access pass. We will verify your identity first, then you can register the new phone with the pass.
4. Check that the phone's date and time are set automatically, otherwise codes will be rejected.

Never approve a sign-in request you did not start. If you receive requests you did not make, report it as a security incident straight away.
